# Marea Studio

Primera versión del sitio oficial de Marea Studio, construida como un sitio estático, accesible y responsive.

## Desarrollo local

No requiere instalación de dependencias. Levantá un servidor estático desde la raíz:

```bash
python3 -m http.server 4173
```

Luego visitá `http://localhost:4173`.

## Estructura

- `index.html`: contenido, estructura semántica y metadatos SEO.
- `styles.css`: sistema visual, componentes y adaptación responsive.
- `script.js`: navegación móvil y envío progresivo del formulario por email.
